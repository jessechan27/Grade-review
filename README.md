# 成績查詢系統（MLB 風格）

學生輸入自己的學號，即可查詢個人各項成績與目前總分。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `Grade review.xlsx` | 成績來源。**平常只要改這個檔案就好。** |
| `build.py` | 讀 Excel → 產生 `index.html` 的程式 |
| `template.html` | 網頁版型（版面、顏色、文字） |
| `index.html` | **產生出來的網站**，就是要給學生用的檔案 |
| `secrets.json` | 🔒 查詢碼與管理員主密碼。**絕不上傳、絕不刪除** |
| `查詢碼名單.csv` | 🔒 要發給學生的查詢碼名單（可匯入 Moodle） |

## 網站位置

* 線上網址：<https://jessechan27.github.io/Grade-review/>
* 原始碼：<https://github.com/jessechan27/Grade-review>

## 更新成績的步驟

1. 在 `Grade review.xlsx` 填入新的成績。
2. 存檔並關閉 Excel。
3. 在這個資料夾打開 Git Bash / PowerShell，執行：

   ```
   python build.py
   git add index.html
   git commit -m "Update grades"
   git push
   ```

4. 約 1 分鐘後線上網站就會更新。

> 每次執行 `build.py` 都會換一組新的加密鹽值，這是正常的。

## ⚠ 重要：不要把 Excel 上傳到 GitHub

`Grade review.xlsx` 含有全班的明文姓名與成績，而這個 GitHub repo 是**公開**的。
`.gitignore` 已經設定成自動排除所有 `.xlsx` / `.xls` / `.csv`，正常操作不會誤傳。

若要確認，執行以下指令，結果應該是空的：

```
git ls-files | grep -i xlsx
```

## 兩種登入方式

### 學生：學號 + 查詢碼
學生必須同時輸入自己的學號與**專屬查詢碼**才能查到成績。
查詢碼大小寫不分、中間的 `-` 可省略。

* 加密金鑰 = `PBKDF2(學號 + "|" + 查詢碼)`，所以**沒有查詢碼就解不開該生的成績**，
  不是只有畫面擋住而已。
* 知道別人學號也沒用，一定要有該人的查詢碼。
* 查詢碼存在 `secrets.json`，重新執行 `build.py` 會沿用，
  **學生手上的碼不會失效**。新加入的學生才會配新碼。

查詢碼名單在 `查詢碼名單.csv`，建議透過 Moodle 個別發給學生
（Moodle 成績簿的「個別回饋」欄位可以一次匯入）。

### 教師：管理員主密碼
在查詢頁面點「教師管理端登入」，輸入主密碼即可看到**全班成績總表**，
可搜尋、可匯出 CSV。主密碼在 `secrets.json` 的 `admin_password` 欄位。

> 主密碼要改成自己好記的字串，直接編輯 `secrets.json` 再重跑 `build.py` 即可。
> 只能用英文字母和數字（大小寫不分，`-` 會被忽略）。
> **請設得夠長**（建議 16 字以上）——網站是公開的，密碼強度就是全班成績的防線。

## ⚠ 絕對不要上傳的檔案

| 檔案 | 外洩後果 |
|---|---|
| `Grade review.xlsx` | 全班明文成績 |
| `secrets.json` | 所有查詢碼 + 主密碼 = 等同全班成績 |
| `查詢碼名單.csv` | 同上 |

`.gitignore` 已經自動排除這三類。確認指令（應該沒有任何輸出）：

```
git ls-files | grep -iE "xlsx|secrets|名單"
```

同時請**備份 `secrets.json`**。弄丟的話所有學生的查詢碼都要重發。

## 成績計算方式

* 權重直接從 Excel 標題列讀取，例如標題寫「口頭簡報（50%）」就是 50%。
  **要調整權重，改 Excel 的標題文字即可**，不用改程式。
* 總分 = 各項「分數 × 權重%」加總。
* 尚未評分（儲存格空白）的項目一律以 **0 分**計入總分。
* 標題為「點名扣分」的欄位會從總分中直接扣除。
* 標題為「學期總分」的欄位會被忽略（由網頁自行計算）。

目前的項目與權重：

| 項目 | 權重 |
|---|---|
| 口頭碳排 | 30% |
| 口頭簡報 | 50% |
| 九宮格 | 5% |
| 心得報告 | 4.85% |
| ISO14064-1 | 10% |
| 學習單 | 0.15% |

## 隱私保護

每位學生的姓名、班級與成績都用**自己的學號＋查詢碼**加密後才寫進 `index.html`：

* 直接看網頁原始碼只會看到亂碼，看不到任何人的成績、姓名或查詢碼。
* 解密與計算全部在學生自己的瀏覽器完成，不會傳到任何伺服器。
* 全班名冊另外用主密碼加密成一份資料，只有輸入主密碼才解得開。

## 修改網頁標題

打開 `template.html`，找到最下方的 `var COURSE = {` 區塊：

```js
var COURSE = {
  title:  "成績查詢系統",          // 大標題
  kicker: "Student Grade Lookup",  // 標題上方小字
  tag:    "",                      // 右上角文字，例如 "114-1 學期"
  footer: "成績資料來源：Grade review.xlsx"
};
```

改完後再執行一次 `python build.py`。

## 需求

* Python 3 + `openpyxl`（安裝：`pip install openpyxl`）
* 學生端：任何現代瀏覽器（Chrome / Edge / Safari / Firefox），可直接開啟 `index.html`，
  不需要網路連線也能查詢。
